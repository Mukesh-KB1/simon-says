# 🎮 Simon Says Game

A fun and interactive memory game built using HTML, CSS, and JavaScript.  
Test your memory by repeating the sequence of colors correctly!

---

## 🚀 Live Demo
👉 simon-says-challenge4u.netlify.app

---

## 🧠 How It Works

- The game shows a sequence of colors
- You must repeat the sequence in the correct order
- Each level adds a new step to the sequence
- One mistake → Game Over
